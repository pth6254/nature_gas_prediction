# 전통 시계열 비교: 소규모 후보 BEST

가격 이력만 사용하는 7개 후보를 동일 원점에서 비교했다. 범위가 제한된 빠른 비교이며 통계 모델 전체의 최적해가 아니다.

| 후보 | H1 MAPE | H2 MAPE | H3 MAPE |
|---|---:|---:|---:|
| Last Value Naive | 7.6663% | 10.4804% | 13.5698% |
| Seasonal Naive | 27.2084% | 27.4281% | 27.7289% |
| 단순 지수평활 | 7.6663% | 10.4804% | 13.5698% |
| 감쇠 추세 지수평활 | 7.6663% | 10.4805% | 13.5698% |
| 감쇠 추세 + 12개월 가법 계절 지수평활 | 8.0836% | 10.1080% | 13.4857% |
| ARIMA(1,1,0) | 7.6728% | 10.4583% | 13.5624% |
| SARIMA(0,1,1)(0,1,1,12) | 8.1197% | 10.0566% | 13.3823% |

H1은 Naive를 대표 BEST로 둔다. 단순 지수평활과 수치적으로 동률이며 MAPE 차이 0.0001퍼센트포인트 이내는 Naive를 우선했다.
H2/H3의 전체 구간 고정 후보 BEST는 SARIMA(0,1,1)(0,1,1,12)다.
이 표는 전체 결과를 보고 고른 사후 순위다. 기존 ML 비교에서 쓰던 원점과 같으므로 다음 계열 비교의 참고 기준으로 사용한다.
기존 ML 선택 모델의 MAPE 6.8272/9.4613/13.2846%보다 이번 통계 BEST의 MAPE는 세 horizon 모두 높다.

## 과거 성적 기반 선택과의 차이

이전 조합 실험과 같은 규칙으로 각 원점까지 정답이 알려진 최근 최대 36개월 내부 MAPE를 비교했다.
과거 기반 선택 MAPE는 H1 7.6580%, H2 10.3740%, H3 14.3226%다.
H3는 Naive보다 나쁘므로 사후 SARIMA BEST의 성능을 당시 선택 절차의 성능으로 표현해서는 안 된다.

## 계산 및 진단

- 기본 비교 구간: 2013-09부터 H1 83개, H2 82개, H3 81개 원점.
- 내부 예측 생성은 2009-09부터, 학습은 매 원점까지 확장한다. 가격 현재값이 알려졌다고 가정한다.
- ETS 계열은 statsmodels Holt-Winters 지수평활 구현이다. 전체 ETS 오류·추세·계절 조합을 자동 탐색한 것은 아니다.
- 학습 후보는 log price를 적합하고 예측을 exp로 변환했다. 평균 편향 보정은 하지 않았다.
- 계절 차수는 12, ARIMA/SARIMA 차수는 미리 소수 후보로 정했다. 광범위한 차수 탐색이 아니다.
- 수렴 실패 또는 비정상 예측은 Naive로 대체하고 기록했다. ARIMA(1,1,0)는 외부 평가에서 horizon마다 2개 원점이 대체되었다. 해당 성능은 대체 규칙까지 포함한 결과다.
- 최종 SARIMA 후보는 외부 평가 원점에서 대체가 없었다. 전체 내부 기록은 fit_diagnostics.csv에서 확인한다.
- 지수평활의 아주 작은 예측 변화가 정확 부호 기반 반전 F1을 높일 수 있었다. 따라서 0.1% 이하 변화를 평탄으로 처리한 별도 진단을 추가했다. 실제·예측·직전 변화에 같은 기준을 적용하며 원래 MAPE와 정확 부호 지표는 그대로 저장한다.
- 0.1%는 설명용 고정 진단 기준이며 최적화한 값이 아니다. Naive와 거의 같은 지수평활의 정확 부호 F1을 실질적 반전 포착 능력으로 강조하지 않는다.

재현: `uv run python -m src.statistical_experiment`.
사후 BEST는 best_fixed.csv, 전체·연도별 지표는 metrics.csv, 원점별 선택 점수는 selection_scores.csv에 저장한다.
기존 submission.csv는 변경하지 않았다. 이번 결과로 통계 비교군을 정리하고 ML·DL 비교를 이어간다.
