# 현재 수급·시장 조합에 대한 총수입·리그의 추가 기여

## 결론

**이번 범위에서는 총수입·리그를 일괄 추가하지 않는 쪽을 권한다.** 단독 가격 이력 기준의 개선이 기존 가공 수급·시장 조합 위의 안정적 개선으로 이어지지는 않았다. 과거 성적으로 추가 여부까지 선택한 절차도 H1 ElasticNet, H2/H3 Ridge에서 모두 악화했다.

- H1 ElasticNet: 기본6.314%, 리그6.313%의 차이는 약−0.0006%p이며 전후반 부호가 다르다. 총수입은6.325%로 악화했다.
- H2 Ridge: 총수입 고정 추가는9.212→9.071%지만 전반−0.375%p, 후반+0.092%p다. 5/8개 연도 개선, block6 구간−0.802~+0.508%p로 안정적 우월성을 확인하지 못했다.
- H3 Ridge: 총수입은11.723→11.721%의 미세한 차이다. 리그/둘다 추가는 악화했다.
- 추가 여부까지 과거 선택한 all 정책: H1 ElasticNet6.422%, H2 Ridge9.281%, H3 Ridge11.795%로 모두 기본 정책보다 나쁘다.

## 원천과 고정 실험 조건

[재고 원천 확인](../outputs_storage_source/FINDINGS.md): 204개월 모두 EIA 월별 총저장량을10 MMcf 단위 반올림한 값과 일치했다. working gas와 구분하고2013년 알래스카 포함 범위 변경을 기록했다. 새 실험의 재고는 **lag2 고정**으로 성능을 보고 공표 지연을 고르지 않는다. 원 제공자의 수집 경로·과거 빈티지·전 기간 최초 공표 달력은 여전히 미확인이다.

조합은 base/imports/rigs/both 4개다. 총수입·리그 각각 수준+1차 차분2특징, 전기가격·PPI·CLI로 탐색 확대하지 않았다. Ridge alpha10, ElasticNet alpha0.01/l1_ratio0.2, LightGBM 기존 설정을 유지했다. H1은 가격 이력18+핵심4, H2/H3는 가격 이력8+핵심4다. 생산/소비/재고/수입 공표lag2, 리그/시장lag0은 실험 가정이다. 학습 구간에서만 중앙값·결측 표시·스케일러를 적합한다. 추가 변수의 전방채움은 최대1개월이다.

H1은 각 추가 조합별 동일하게 핵심 생산·재고·소비 반응 시차0/1/3/6을 최근36개 알려진 과거 정답(최소24)으로 선택한다. 추가 수입/리그 자체의 반응 시차는 따로 탐색하지 않았다. all은 조합도 함께 선택한다. H2/H3는4개 고정 조합 및 과거 조합 선택 정책을 비교한다.

내부 원점72, 외부120부터, 모든 학습·선택 라벨j+h≤원점. H1/H2/H3 각각83/82/81개 동일 원점. 총9,396회 적합, 경고0건. 기존 CPU 추정기를 유지하고 DL/GPU 재학습은 하지 않았다. 테스트 자료는 읽지 않았으며 submission.csv를 보존했다.

## 후속 결정과 한계

새 변수 추가 없이 H1 ElasticNet+과거 반응 시차 선택, H2/H3 Ridge basic_processed, 재고 공표lag2를 우선 최종화 후보로 제안한다. 실제 최종 파이프라인·제출은 아직 고정/생성하지 않았다. 반복 열람한 검증자료에서 발상한 후보이므로 과거 내부 선택이 안전해도 독립 검증을 통과한 최적 모델이라는 뜻은 아니다.
