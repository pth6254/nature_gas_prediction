# Henry Hub 분석 발표자료

[REPORT_SLIDES.html](REPORT_SLIDES.html)을 Chrome 또는 Edge로 열면 16:9 슬라이드 10장이 표시됩니다. 인터넷 연결 없이 그래프·수치·이동 기능을 사용할 수 있습니다. HTML 자체는 PowerPoint의 `.pptx` 파일이 아닙니다.

## 사용

- `←` / `→`, PageUp / PageDown: 이동. Home / End: 처음 / 마지막.
- `F`: 전체 화면. `N`: 발표 노트. 모바일: 좌우 스와이프.
- `인쇄 / PDF`: 브라우저 인쇄에서 PDF로 저장. 16:9 페이지가 한 슬라이드씩 출력되도록 인쇄 스타일을 지정했습니다. 머리글/바닥글을 끄고, 배율 100%, 배경 그래픽 켜기를 권장합니다. 브라우저 미리보기에서 10페이지인지 확인하세요.
- 근거 링크를 사용하려면 프로젝트 내부의 현재 `presentation/` 위치를 유지하세요. HTML만 복사해도 그래프는 표시되지만 상대 경로의 보고서·소스 링크는 연결되지 않습니다.

## 과제 요구사항 대응

안내 PDF는 분석 보고서를 **슬라이드 10장 내외**로 요구하며 보고서 확장자는 명시하지 않았습니다. HTML 접수 가능 여부는 별도 제출 채널의 제한이 있으면 확인해야 합니다. 이 파일만으로 전체 제출 요구가 충족되는 것은 아닙니다.

| 과제 요구 | 슬라이드 |
|---|---|
| 데이터 분석·시각화 | 2–4 |
| 변수 선택과 관계·가용성 | 3–5 |
| 예측 모델·선정 이유 | 5–7, 10 |
| 예측 오차 MAPE | 1, 6–8 |
| 오차·변곡점·변수 기여 설명 | 8–9 |
| 외부 자료를 사용한 경우 설명 | 4 및 발표 노트: EIA는 원천 확인용, 예측 입력 추가 아님 |
| CSV 예측 형식·재현 소스 | 10, 프로젝트의 submission.csv 및 src/ |

제출은 보고서 + `submission.csv` + 재현 가능한 전체 소스·환경 안내를 함께 준비해야 합니다. 접수 후 3일 이내라는 기한 준수 여부는 별도로 확인해야 합니다.

## 수치와 해석

모든 그래프는 저장된 CSV의 실제 수치로 생성합니다. `build_deck.py`는 원점별 예측으로 최종 MAPE와 Naive MAPE를 재계산하고 83/82/81개 검증 원점 및 48행 제출 형식을 검사합니다. 모델 재학습이나 기존 제출 파일 변경은 하지 않습니다.

- 3·6·7장 및 4장의 공통 입력 감사: 초기 탐색이며 재고 공표 lag1.
- 4장의 신규 변수군 실험, 5·8–10장의 최종 설정·결과: 월별 수급 공표 lag2.
- 초기 사후 BEST와 과거 성적 기반 선택 정책을 구분합니다.
- 반복 열람한 훈련자료 내 검증이지 독립 홀드아웃·대회 테스트 점수가 아닙니다.
- 7장의 NBEATSx 수치는 3개 시드 평균 중 사후 선택한 입력 조합입니다. DL의 제한된 학습 예산과 Chronos-2 재평가는 발표 노트에 설명했습니다.
- 선형 기여는 로그 수익률 공간의 모델 설명이며 인과효과가 아닙니다.

## 재생성 및 검수

프로젝트 루트에서:

```powershell
.venv\Scripts\python.exe presentation/build_deck.py
node presentation/verify_deck.mjs
```

`slides.template.html`은 편집 원본, `REPORT_SLIDES.html`은 데이터가 포함된 완성본입니다. `evidence_manifest.json`은 출처 해시와 차트 데이터, `qa_report.json`은 Chrome 렌더링·텍스트 겹침·이동·인쇄 레이아웃 검사 결과입니다. 검수 스크립트는 Windows의 설치된 Chrome과 Node의 내장 WebSocket을 사용합니다. 캡처는 `tmp/slide_build/`에 저장합니다.

새 모델 실험을 수행하지 않은 문서 작업입니다. 슬라이드의 60개 테스트 통과는 기존 최종 실행 기록이며, 이 발표자료 생성 중 모델 테스트를 새로 실행했다는 뜻은 아닙니다.

## 안내문의 평가 항목을 반영한 수정

안내문에는 세부 배점이나 합격 기준은 없고, 보고서 필수 항목 및 가산점 항목이 있습니다. 아래는 그 항목에 대응한 작성 내용이지 자체적으로 매긴 점수가 아닙니다.

| 안내문 항목 | 수정한 내용 | 확인 범위 |
|---|---|---|
| 데이터 분석·변수 간 관계 | 2–3장: 관측 수, 가격 움직임, 생산·재고·소비·시장 선택 이유 | 공급·수요 관계는 출발 가설이며 인과관계 입증이 아님 |
| 데이터 선택 과정의 합당성 | 3–4장: 가공 이유, 보류 이유, 변수 제거, 발표 지연 | 78개는 조건부 실험 대상이며 전체 실시간 가용성을 보장하지 않음 |
| 데이터 특성에 맞는 모델 선정 | 6–7장: 같은 입력 조합 비교, 소표본과 규제, H1/H2/H3 선택 이유 | 모델의 성질과 관측 결과를 구분. 작은 표본이 성능 차이의 원인임을 입증하지는 않음 |
| 예측 오차 MAPE | 5·8장: 쉬운 계산 예시, 최종 수치, 현재 가격 유지 기준선 | 훈련자료 내 반복 검증. 대회 점수·독립 평가가 아님 |
| 정확한 변곡점 예측 | 8–9장: 반전 F1과 성공·실패 사례의 가격·오차 | 반전 정의 명시. 일부 성공을 전체 정확성으로 일반화하지 않음 |
| 변곡점 이유·입력과 목표의 물리적 관계 | 3·9장: 수급 가설과 예측을 올리고 내린 입력 연결 | 실제 가격 반전의 외부 원인 검증은 미완료. 그 한계를 본문에 표시 |
| 외부 자료·소스 코드 | 4·10장: EIA 원천 확인 목적, CSV 날짜 의미, 재현 명령 | CSV 및 전체 코드·환경 안내를 별도로 제출해야 함 |

10장 틀과 그래프는 유지하고 영어 표제·추상적인 표현을 줄였습니다. 상세 DL 나열은 줄이고 변수와 모델의 선택 이유에 분량을 배정했습니다. 이전 슬라이드는 프로젝트 밖의 정리 백업으로 이동했습니다. 모델 코드 및 `submission.csv`는 변경하지 않았습니다.
