## 고정 모델

- H1: ElasticNet(alpha=0.01, l1_ratio=0.2), 가격 이력18+가공 수급·시장4. 생산·재고·소비의 추가 반응 시차0/1/3/6만 매월 알려진 과거36개 예측 성적(최소24)으로 선택한다.
- H2/H3: Ridge(alpha=10), 기본 가격 이력8+생산 수준·재고 계절Z·소비 누적Z·BCOMNG 수익률의12특징. 반응 시차 추가 없음.
- 생산·재고·소비 공표 지연2개월, BCOMNG0개월. 총수입·리그·기타 후보는 최종 입력에 포함하지 않는다.
- 목표는 log(P[t+h]/P[t]), 가격 복원은 max(0.01,P[t]×exp(예측값)). 현재 가격과50:50 평균하거나 고정 수급 합성식을 쓰지 않는다.

## 제출

submission.csv는2020-09-30~2024-08-31의48개 예측 원점, date/pred_1/pred_2/pred_3 순서다. 날짜는 목표월이 아니라 예측 수행 월이다. 마지막2024-08-31 행은9/10/11월 가격을 예측한다. 수치는 소수6자리로 저장했다.

각 월말까지 관측된 테스트 가격을 이용해 expanding-window 재학습한다. 학습 행j의 정답은j+h≤t인 경우만 포함하고 H1 선택도 같은 제약을 적용한다. 미래 테스트 행·아직 알려지지 않은 정답은 선택에 사용하지 않는다. 이는 테스트 가격 전체를 처음부터 쓰거나 테스트 점수로 최종 모델을 고르는 것과 다르다.

제출 구간 H1 반응 시차 선택 횟수: {1: 40, 3: 7, 6: 1}. 이것은 사후 최적 시차를 고른 분포가 아니라 사전에 고정한 과거 선택 절차의 실행 기록이다.

원시 생산·재고·소비는 마지막2개월이 결측이다. 공표lag2 이후 실제 제출 원점에 필요한 값은 존재하며 미래 값으로 보간하지 않는다. 실제 최초 발표·개정 빈티지의 전 기간 검증은 미완료라는 한계는 유지한다.
