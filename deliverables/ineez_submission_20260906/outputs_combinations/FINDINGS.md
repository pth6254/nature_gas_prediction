# 2차 조합 검증 결과

8개 고정 조합과 Naive를 비교하고, 각 원점까지 정답이 알려진 최근 최대 36개 내부 검증 월의 MAPE로
후보를 고르는 `past_selected` 절차를 평가했습니다. 고정 모델은 모두 Ridge alpha=10입니다.

## 과거 성적 기반 선택 절차

| 예측 기간 | Naive MAPE | 기존 모델 MAPE | 과거 기반 선택 MAPE | 기존 반전 F1 | 과거 기반 선택 반전 F1 |
|---|---:|---:|---:|---:|---:|
| H1 | 7.6663% | 6.8272% | 6.6817% | 67.4419% | 71.7391% |
| H2 | 10.4804% | 9.4613% | 10.0411% | 56.4103% | 46.3768% |
| H3 | 13.5698% | 13.2846% | 13.9031% | 60.7595% | 52.6316% |

H1은 추가 확인 후보입니다. H2는 기존 모델보다 나쁘고, H3는 Naive보다 나쁩니다.
세 horizon을 일괄 교체할 근거가 없으므로 기존 제출 모델은 유지합니다.

## 고정 조합 진단

| 조합 | H1 MAPE | H2 MAPE | H3 MAPE |
|---|---:|---:|---:|
| A: 생산 Z / 재고 Z | 7.5243% | 10.6862% | 14.1240% |
| B: 생산 수준 / 재고 Z | 7.3847% | 9.8118% | 12.6088% |
| C: 생산 Z / 재고 계절 Z | 7.2628% | 10.2202% | 13.3061% |
| D: 생산 수준 / 재고 계절 Z | 7.3299% | 9.5726% | 12.3125% |
| A + BCOMNG 수익률 | 6.6487% | 10.4939% | 14.0243% |
| B + BCOMNG 수익률 | 6.5565% | 9.5142% | 12.2011% |
| C + BCOMNG 수익률 | 6.4678% | 10.1234% | 13.2729% |
| D + BCOMNG 수익률 | 6.3946% | 9.3131% | 12.0778% |

가격 이력과 소비 Z는 모든 조합에서 동일합니다. BCOMNG는 수급 수식에 더한 것이 아니라 별도 입력 특징입니다.
BCOMNG 추가는 각 조합의 전체 MAPE를 세 horizon 모두에서 낮췄습니다.
생산 수준과 재고 계절편차를 함께 사용하는 D는 시장 변수 없이 H1의 C보다 나쁘므로,
개별 특징의 개선이 항상 결합 개선으로 이어지는 것은 아닙니다.

D_market은 이번 전체 구간에서 가장 낮지만, 이는 전체 결과를 본 후의 순위입니다.
과거 성적 기반 선택은 H3에서 이 후보를 81개월 중 10개월만 선택했고, 전체 MAPE도 나빴습니다.
따라서 D_market의 사후 최저값을 당시 선택할 수 있었던 절차의 성능과 동일시하면 안 됩니다.
선택 기간 36개월의 민감도와 후보 전환 안정성은 후속 가설이며 이번 실행 후 다시 최적화하지 않았습니다.

## 검증과 한계

- H1/H2/H3 각각 83/82/81개 동일 원점에서 모든 후보와 기준선을 비교했습니다.
- 내부 정답의 최종 시점 <= 외부 예측 원점, 원점별 정확히 하나의 후보 선택, 유한 예측값과 중복 없는 키를 확인했습니다.
- 테스트 17개 통과. 아직 관측되지 않은 정답을 바꿔도 선택 결과가 바뀌지 않는 검사를 포함합니다.
- 조합은 이미 탐색한 데이터에서 얻은 가설입니다. 과거 정보만 사용하는 선택 절차를 구현했어도 완전히 새로운 독립 평가가 아닙니다.
- 기존 모델도 전체 검증으로 선택했던 참고 기준이며, 이번 선택 후보군에는 포함하지 않았습니다.
- 모델 종류, 규제 강도, 앙상블 비율을 고르는 실험은 이번 범위가 아닙니다.
- 기존 submission.csv와 최종 모델 설정을 변경하지 않았습니다.

재현: `uv run python -m src.combination_experiment`
가설·계산식·선택 설정은 `manifest.json`, 모든 내부 점수는 `selection_scores.csv`에서 확인합니다.
