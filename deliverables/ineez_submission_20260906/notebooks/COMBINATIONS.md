# 2차 실험: 특징 결합과 과거 성적 기반 선택

```powershell
uv run python -m src.combination_experiment
```

## 가설과 통제 조건

가격 이력과 소비 Z값은 고정하고 아래 네 조합을 비교합니다.

| 조합 | 생산 | 재고 |
|---|---|---|
| A | 누적 Z값 | 누적 Z값 |
| B | 원자료 수준 | 누적 Z값 |
| C | 누적 Z값 | 과거 동일월 계절 Z값 |
| D | 원자료 수준 | 과거 동일월 계절 Z값 |

각 조합에 BCOMNG 1개월 수익률을 추가한 `_market` 후보도 계산하므로 총 8개입니다.
B-A, C-A로 단독 교체 효과, D-B와 D-C로 결합의 추가 효과를 확인합니다.
각 `_market`과 원 조합을 비교하면 시장 정보의 추가 효과를 볼 수 있습니다.
모든 후보는 동일한 Ridge log-return(alpha=10), 보수 발표 지연, 학습 구간 전처리를 사용합니다.
표현을 바꾸는 것과 단위 크기 효과를 혼동하지 않도록 생산 수준 역시 모델 직전 학습 구간 기준으로 표준화합니다.

## 선택과 평가 분리

내부 예측은 인덱스 72(2009-09)부터 각 시점의 관측 가능한 정답으로만 학습해 생성합니다.
외부 평가 원점은 기존과 동일한 인덱스 120(2013-09)부터입니다.
외부 원점 t에서 사용할 수 있는 내부 예측은 j+h<=t를 만족하는 j의 예측뿐입니다.
이 중 최근 최대 36개 월의 MAPE를 비교해 8개 조합 또는 Naive 중 하나를 선택합니다.
최소 내부 관측 수는 24이며 부족하면 실행을 중단합니다. 동점은 Naive, 그다음 이름 순서입니다.
36개월은 이번 실험의 고정 설계이며 최적화된 기간이 아닙니다.

선택한 조합은 t까지 알려진 학습 정답으로 적합한 모델을 통해 t의 미래 가격을 예측합니다.
후보의 원점별 예측을 캐시해 재사용하지만, 각 예측은 해당 원점에서 학습한 결과이므로
매 외부 원점에서 내부 검증을 다시 계산하는 것과 같은 과거 정보만 사용합니다.
정답이 아직 알려지지 않은 내부 예측은 선택 점수에 포함하지 않습니다.

`past_selected`가 이 선택 절차의 평가 결과입니다. 전체 평가 구간에서 가장 좋은 고정 후보와 구분하세요.
고정 후보별 지표는 가설 해석을 위한 진단이며, 사후 최저값 자체를 선택 절차의 성능으로 보고하지 않습니다.
Ridge 규제 강도·모델 종류·앙상블 비율 선택은 이번 실험 범위에 포함하지 않습니다.

## 기존 모델 비교의 한계

`legacy_reference`는 기존 H1 E3 ElasticNet, H2 E3 Ridge, H3 E2 Ridge를 같은 날짜에서 재계산합니다.
이 모델 이름과 특징은 과거 전체 검증 결과로 선택했던 것이므로 사후 선택된 참고 기준입니다.
과거 기반 선택 후보군에는 넣지 않습니다. Naive가 사후 선택되지 않은 공통 기준선입니다.

이번 8개 조합 자체도 이미 살펴본 데이터에서 얻은 아이디어로 구성했습니다.
따라서 과거 정보만 사용하는 선택 구현이더라도 완전히 미관측인 독립 검증 결과는 아닙니다.
테스트 데이터와 기존 제출 파일은 읽거나 수정하지 않습니다.

## 산출물

`outputs_combinations/manifest.json`에 입력 해시, 전체 특징 목록과 선택 규칙을 기록합니다.
`feature_definitions.csv`는 원자료·변환·지연을 연결합니다.
`inner_prediction_cache.csv`는 원점별 내부 후보 예측,
`selection_scores.csv`는 외부 원점별 모든 후보 점수와 실제 선택 결과를 제공합니다.
`predictions.csv`, `metrics.csv`, `comparisons.csv`로 전체·연도별 성능 및 조합별 차이를 확인합니다.
MAPE 차이는 퍼센트포인트이며 음수일수록 비교 대상보다 개선입니다.
