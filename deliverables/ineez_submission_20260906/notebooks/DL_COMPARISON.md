# 소규모 딥러닝 비교 실험

## 목적과 후보

204개월 단일 시계열에서 신경망이 추가적인 예측 이득을 주는지 확인한다. MLP를 작은 신경망 기준선으로 두고, 외생변수를 지원하는 NBEATSx와 TFT를 비교한다. 복잡한 모델이 더 우수하다고 가정하지 않는다.

공식 NeuralForecast의 모델 클래스를 사용하되, 데이터 창 생성·정규화·최적화·조기 종료는 `src/dl_experiment.py`의 명시적 PyTorch 루프로 구현했다. 라이브러리 기본 Trainer를 사용한 벤치마크가 아니다.

| 모델 | 고정 구조 |
|---|---|
| MLP | 은닉 폭 32, 2개 은닉층 |
| NBEATSx | identity 스택 2개, 각 1개 블록, 각 MLP 32×32 |
| TFT | hidden size 8, attention heads 2, dropout 0.1 |

NBEATSx는 generic identity 구성이며 추세·계절 성분을 해석하는 분해 실험이 아니다. TFT의 attention도 인과효과로 해석하지 않는다.

## 입력 조합

모든 모델은 최근 24개월 가격을 사용한다.

| 이름 | 추가 입력 |
|---|---|
| price | 없음 |
| fundamentals | 생산 수준, 재고의 동일 월 계절 Z-score, 소비의 누적 Z-score |
| market | fundamentals + BCOMNG 수익률 |

이 조합은 앞선 변수 탐색에서 정한 후보이며, 전체 조합의 최적성은 입증되지 않았다. `가격 = 생산 + 재고 - 수요`를 강제로 적용하지 않고 세 변수를 분리해 학습한다. 원시 변수·계산식은 `outputs_dl/feature_definitions.csv`에 저장한다.

생산·소비 2개월, 재고 1개월의 보수적 가용성 지연을 적용한다. BCOMNG는 원점 당월까지 관측 가능하다는 기존 가정을 따른다. 외생변수는 과거 관측 입력으로만 사용하고 미래의 실제 생산·재고·소비·시장값은 주지 않는다. TFT에 미래 외생변수를 지정하지 않을 때 라이브러리는 마지막 입력 가격을 반복한 내부 입력을 사용하며 미래 정답을 참조하지 않는다.

## 학습과 누수 방지

- H1·H2·H3의 표준화 로그 가격을 한 번에 직접 예측하고 역표준화 후 exp로 가격을 복원한다. 재귀 예측이 아니다.
- 외부 평가 원점은 기존 비교와 동일한 120~202번이다. H1 83개, H2 82개, H3 81개 사례를 평가한다.
- 매 원점 t에서 j+3≤t인 과거 창만 학습·검증 후보로 사용한다. 마지막 12개 원점은 내부 검증으로 분리한다.
- 학습 타깃의 마지막 시점이 첫 검증 원점 이하여야 하므로 겹치는 타깃을 가진 경계 창 2개를 제외한다. 검증 입력 이력이 학습 이력과 겹치는 것은 허용하되 검증 정답은 학습하지 않는다.
- 가격 정규화, 결측값 대체, 외생변수 스케일러는 마지막 학습 타깃 시점까지로 적합한다. 내부 검증 정답이나 외부 미래값으로 적합하지 않는다.
- Adam(lr=0.001, weight_decay=0.0001), 전체 배치, gradient clipping=1, 최대 80 step을 사용한다. 학습 손실은 표준화 로그 가격 MSE다.
- 10 step마다 내부 검증 가격 MAPE를 확인하고, 2회 연속 개선되지 않으면 종료한다. 최저 검증 MAPE 가중치를 복원한다. 검증 데이터를 합쳐 다시 학습하지 않는다.
- seed 11·42·77을 반복하고 MAPE 평균·표본 표준편차·최소·최대를 모두 저장한다. 최고 시드 하나를 최종 성능으로 제시하지 않는다.

## 비교 해석의 한계

기존 ML은 horizon별 로그 수익률 회귀이고 DL은 공동 3출력 로그 가격 회귀다. 또한 DL은 조기 종료용 내부 검증을 학습에서 제외한다. 따라서 동일 외부 원점의 실용적 파이프라인 비교이지, 구조만 바꾼 완벽한 통제 실험은 아니다.

24개월 입력·작은 네트워크·80 step은 실행 비용을 제한하기 위한 사전 고정값이지 검증된 최적값이 아니다. 성능이 낮아도 딥러닝 전체가 부적합하다고 결론 내리지 않는다. 시드 3개의 표준편차는 초기화 민감도이며 시간 표본에 대한 신뢰구간이 아니다.

전체 외부 결과를 본 후 가장 좋은 입력 조합을 고른 수치는 **사후 탐색 결과**다. 과거 성적만으로 조합을 선택한 ML 절차와 구분해야 한다. 반복해서 탐색한 동일 구간은 미사용 최종 홀드아웃이 아니다.

## 재현

```powershell
uv sync --extra dev --extra dl
uv run --extra dl python -m src.dl_experiment
uv run --extra dl python -m src.dl_report
uv run --extra dev --extra dl python -m pytest -q -p no:cacheprovider
```

CPU 단일 스레드로 실행한다. 설정·코드·학습 데이터 해시가 같은 실행은 완료 원점을 재사용하며, 다른 설정은 별도 출력 폴더를 지정해야 한다. `outputs_dl/`에 원점별 예측·학습 진단·전체 및 연도별 지표·시드 안정성을 저장한다. 제출 파일은 변경하지 않는다.

공식 구조 설명: [MLP](https://nixtlaverse.nixtla.io/neuralforecast/models.mlp.html), [NBEATSx](https://nixtlaverse.nixtla.io/neuralforecast/models.nbeatsx.html), [TFT](https://nixtlaverse.nixtla.io/neuralforecast/models.tft.html).
