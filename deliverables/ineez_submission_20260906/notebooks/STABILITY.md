# 최종 후보의 규제 강도·기간 안정성 검증

## 사전 고정 범위

앞선 실험에서 H1은 수급 반응 시차 선택, H2/H3는 가격 특징 간소화가 유망했다. 두 후보를 그대로 최종 채택하지 않고 규제 민감도·과거 선택의 실효성·기간 및 급변 구간 안정성을 확인한다. 모델 추가나 제출 파일 교체는 하지 않는다.

- 모델: Ridge(alpha=1, 10, 100), ElasticNet(alpha=0.001, 0.01, 0.1; l1_ratio=0.2 고정).
- 기존 중심값: Ridge 10, ElasticNet 0.01. 나머지 파이프라인·학습 손실·CPU 설정은 이전 실험과 동일하다.
- H1 입력: current 및 수급 세 특징의 공통 추가 시차 1/3/6개월. 가격·시장 입력의 시차는 유지한다.
- H2/H3 입력: current와 basic_processed. 후자는 가격 8개 기본 시차·월 특징 + 생산 수준·계절 재고 Z·소비 Z·BCOMNG 수익률이다.
- 보수적 발표 지연과 horizon별 로그 수익률 타깃을 유지한다. 결측 대체 및 스케일러는 각 학습 구간에서만 적합한다.

## 고정 후보와 선택 절차 구분

고정 후보는 각 원점에서 해당 입력·alpha로 학습한다. 전체 구간의 고정 후보 성능표는 민감도 진단이며 최저값을 사전 선택 결과로 주장하지 않는다.

| 절차 | 적용 기간 | 선택 범위 |
|---|---|---|
| current_alpha | H1/H2/H3 | 현재 입력에서 규제 3개 중 선택 |
| lag_fixed_alpha | H1 | 기존 규제 강도를 유지하고 추가 시차 0/1/3/6 중 선택 |
| lag_alpha | H1 | 추가 시차 4개 × 규제 3개를 공동 선택 |
| basic_alpha | H2/H3 | 간소화 입력에서 규제 3개 중 선택 |

각 모델 계열 내부에서 선택하며 Naive는 후보 풀에 넣지 않는다. Naive와 같은 계열의 현재 고정 모델을 참조로 평가한다. H2/H3에서는 간소화 고정 규제 후보와도 비교한다.

## 시간 순서

고정 후보 예측을 내부 원점 72부터 생성한다. 각 예측은 그 원점에 정답이 알려진 j+h≤t 학습 사례만 이용한다.
외부 원점 120부터 선택 시점 이전에 정답이 확인된 과거 예측들의 MAPE로 후보를 고른다.

- 주 선택 기간: 최근 최대 36개 과거 원점.
- 민감도: 최근 최대 24개/48개.
- 최소 내부 사례: 24개. 48개가 아직 없으면 가용 과거 사례만 사용하며 실제 개수를 기록한다.
- 24/48개월 결과 중 가장 좋은 것을 골라 주 분석 36개월 수치를 대체하지 않는다.
- 외부 H1/H2/H3 평가 원점은 기존과 같은 83/82/81개다.

## 안정성 진단

MAPE·MAE·방향·반전 F1 외에 P90 절대백분율오차, 최대 오차와 최악 원점도 기록한다.
2013–2016/2017–2020 두 구간 및 연도별 지표를 분리한다. 두 구간은 새 홀드아웃이 아니라 이미 평가한 구간의 사후 분해다.

급변 구간은 |실제 미래 가격/원점 가격−1|≥15%로 고정 정의한다. 이 정의는 정답을 이용한 사후 오차 분석이며 입력 생성·학습·후보 선택에는 사용하지 않는다. 급변 사례 수를 함께 제시한다. 방향 반전과 급변은 다른 진단이다.

## 해석 원칙

평균 개선이 전반·후반 및 급변 구간에서 반복되는지 확인한다. 승리 연도 수는 유의성 검정이 아니다. 가격 오차가 시간적으로 의존하고 후보를 같은 데이터에서 반복 탐색했으므로 독립 최종 성능을 주장하지 않는다.
규제 선택이 고정값보다 나쁘면 불필요한 선택 복잡성을 추가하지 않는다. 한 시점의 점수 차이나 사후 최저 alpha만으로 최종 모델을 교체하지 않는다.
